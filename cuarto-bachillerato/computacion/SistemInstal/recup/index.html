Datos Generales del Estudiante

I SERIE — Conocimientos Fundamentales

Responde los enunciados seleccionando la definición técnica correcta (Valor: 25 pts • 5 pts c/u)

Serie I: 5 preguntas

1. Explique la diferencia entre software propietario y software de código abierto. Indique una ventaja legal de este último.

2. ¿Qué es una máquina virtual? Distinga equipo anfitrión (host), hipervisor y sistema invitado.

3. ¿Para qué sirve el gestor de fuentes de Word y cómo ayuda a evitar el plagio académico?

4. ¿Qué función estructural cumplen las etiquetas semánticas HTML <header>, <nav> y <footer> al organizar un sitio web?

5. Explique qué es la validación de datos y mencione dos reglas que deberían aplicarse en un formulario de soporte técnico.

II SERIE — Selección Múltiple

Marca la respuesta correcta por cada inciso (Valor: 25 pts • 5 pts c/u)

Serie II: 5 preguntas

6. ¿Cuál herramienta de software permite instalar y probar otro sistema operativo (ej. Linux) de forma segura sin borrar ni sustituir el sistema principal de tu computadora?

7. ¿Qué funcionalidad ofimática permite redactar una carta maestra y generar automáticamente copias personalizadas utilizando una tabla de clientes o base de datos?

8. En diseño web, ¿qué etiqueta HTML se utiliza semánticamente para envolver los enlaces del menú principal de navegación?

9. ¿Cuál es una medida técnica apropiada para mantener la calidad y veracidad de los datos recopilados mediante un formulario digital?

10. Como administrador IT, antes de instalar una aplicación comercial o educativa en los laboratorios de computación, ¿qué factores principales debes comprobar para evitar problemas operativos?

III SERIE — Resolución de Casos

Analiza cada caso práctico de gestión y selecciona la acción administrativa o técnica correcta (Valor: 25 pts • 5 pts c/u)

Serie III: 5 preguntas

11. Caso 1: Una oficina administrativa te solicita instalar software privativo utilizando activadores piratas en ocho computadoras porque no tienen presupuesto. ¿Qué alternativa técnica y legal debes proponer?

12. Caso 2: Un estudiante desea practicar la instalación de la distribución Linux Mint en su PC principal, pero teme borrar sus archivos de Windows. ¿Cuál es la solución técnica segura y qué dos precauciones debe tomar?

13. Caso 3: Posees una base de datos en Excel con las columnas «Nombre», «Empresa» y «Correo». Explica cómo generar y enviar correos de actualización tecnológica masivos pero personalizados usando Word.

14. Caso 4: Una empresa de soporte de software recibe tickets donde el correo de contacto no tiene «@» o la descripción del problema está vacía. Proponga dos reglas lógicas de validación para evitar esto desde el diseño de la base de datos.

15. Caso 5: Se construyó un sitio web corporativo con tres páginas diseñadas, pero el menú no permite pasar de la página principal (Inicio) a la página de Contacto. ¿Cuál es el problema lógico de arquitectura y cómo se soluciona?

IV SERIE — Aplicación Técnica y Desarrollo

Evalúa el código, la arquitectura de tablas de datos y citas académicas (Valor: 25 pts)

Serie IV: 3 actividades
16. Estructuración Semántica HTML5 (10 pts) Valor: 10 pts

Requerimiento: Validar el esqueleto de un sitio web que integre jerárquicamente las regiones: <header> con un título H1, <nav> con un enlace ancla a contacto.html, <main> para el contenido central y un <footer> de cierre de derechos.

17. Diseño de Base de Datos y Formulario de Soporte Técnico (10 pts) Valor: 10 pts

Requerimiento: Generar un modelo relacional sencillo (Tabla de Registro) con cuatro campos útiles para IT Support, demostrando cómo se almacenarían 3 tickets de error y aplicando reglas de obligatoriedad (validación).

18. Flujo de Propiedad Intelectual e Inserción de Bibliografía (5 pts) Valor: 5 pts

Requerimiento: Explicar paso a paso el procedimiento metodológico y técnico para utilizar una fuente académica externa en un proyecto informático (Word), respetando las normas APA.
